# 人生重开模拟器（微信小游戏）

一个纯 Canvas 实现的文字人生模拟游戏。选择朝代，随机降生在某个家庭，然后一岁一岁地长大，经历随机事件，直到人生终章。

## 玩法

1. **选择朝代**：唐 / 宋 / 明 / 清 / 现代，各朝代影响基准寿命与事件倾向。
2. **随机出生**：按权重随机抽家庭（贫寒农家 / 普通百姓 / 耕读世家 / 商贾之家 / 官宦门第），生成姓名与初始四维属性。
3. **逐年成长**：点击「继续长大 ▶」推进年龄，每年概率触发随机事件（如「3岁：翻书认字」）。
4. **属性互动**：四维属性——健康 / 智力 / 财富 / 快乐，事件会改变它们；部分事件带分支选择（如被欺负：忍气吞声 / 奋起反抗）。
5. **人生终章**：达到期望寿命后逐年累积死亡概率，或健康归零时病逝，最后给出「传奇 / 显赫 / 顺遂 / 平凡 / 坎坷」的人生评定，可「再活一世」重新开局。

## 运行方式

使用**微信开发者工具**导入本项目根目录，项目类型选择「小游戏」即可在模拟器或真机预览中游玩。

> `project.config.json` 已包含项目配置，`game.json` 配置为竖屏（`portrait`）。

## 目录结构

```
WebChatProject/
├── game.js                    // 入口，调用 main.start()
├── game.json                  // 运行时配置（竖屏）
├── project.config.json        // 微信小游戏项目配置
├── project.private.config.json
└── js/
    ├── main.js                // 主循环 + Canvas 界面 + 触摸交互
    ├── render.js              // 纯 Canvas 渲染（按钮 / 文本 / 进度条 / 高清屏适配）
    ├── game.js                // 核心逻辑：状态机 / 随机生成 / 逐年推进 / 结局
    └── data/
        ├── dynasties.js       // 朝代配置
        ├── families.js        // 家庭背景（含权重）
        └── events.js          // 随机事件库（按年龄触发）
```

## 技术要点

- **纯 Canvas 渲染**：不依赖任何第三方游戏引擎，全部界面由 Canvas 2D 绘制。
- **高清屏适配**：canvas 物理像素 = 逻辑像素 × `pixelRatio`，并使用 `ctx.scale` 还原坐标系，避免手机端字体模糊。
- **事件驱动渲染**：每次触摸先重建界面（刷新可点击区域）再判定点击，保证结局「再活一世」可正常返回。
- **属性驱动剧情**：事件通过 `cond(state)` 条件筛选（如朝代标签、财富阈值），让不同出身有不同人生轨迹。
